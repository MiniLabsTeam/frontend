# MiniGarage

**The Ultimate NFT Car Racing Game on OneChain**

---

MiniGarage is a blockchain-integrated multiplayer racing game where players collect NFT cars, equip spare parts, race against others, trade on the marketplace, and predict race outcomes — all powered by OneChain.

### What Can You Do?

| Feature | Description |
|---------|-------------|
| **Gacha** | Pull random NFT cars and spare parts with OCT tokens |
| **Racing** | 2D Drag Race, 3D Endless, and Multiplayer battles |
| **Marketplace** | Buy, sell, and trade NFT cars with other players |
| **Prediction** | Bet on race outcomes and earn rewards |
| **Quests** | Complete daily & weekly challenges for bonus tokens |
| **RWA** | Claim physical diecast models for legendary cars |
