# Roadmap

## Phase 1 — Foundation *(Completed)*

* [x] Smart contract deployment on OneChain Testnet
* [x] NFT Car and Spare Part minting system
* [x] Commit-reveal gacha with on-chain verification
* [x] Equipment system (equip/unequip spare parts)
* [x] Backend API with Express + TypeScript
* [x] PostgreSQL database with Prisma ORM
* [x] JWT authentication with wallet signing
* [x] Redis caching layer

## Phase 2 — Racing & Gameplay *(Completed)*

* [x] 2D Drag Race game mode (Phaser 3)
* [x] 3D Endless Race mode (Three.js)
* [x] 3D Multiplayer Racing via WebSocket
* [x] Server-authoritative physics engine (60 FPS)
* [x] Obstacle and power-up systems
* [x] Race result signing and on-chain settlement

## Phase 3 — Economy & Social *(Completed)*

* [x] On-chain marketplace (list, buy, cancel)
* [x] Prediction market with pool-based betting
* [x] Quest system (daily/weekly with auto-tracking)
* [x] Real-World Asset (RWA) physical car claims
* [x] Blockchain event indexer

## Phase 4 — Production Launch *(In Progress)*

* [x] Frontend deployment on Vercel
* [x] Backend deployment on Railway
* [x] Neon PostgreSQL + Upstash Redis production infra
* [ ] OneChain Mainnet deployment
* [ ] Public beta launch
* [ ] Mobile-optimized PWA

## Phase 5 — Expansion *(Planned)*

* [ ] Tournament system with leaderboards
* [ ] Clan/team racing
* [ ] Car customization and visual upgrades
* [ ] Additional car brands and collaborations
* [ ] Cross-chain bridge for NFT portability
* [ ] Governance token for community decisions
* [ ] SDK for third-party game integrations

---

> Roadmap is subject to change based on community feedback and ecosystem developments.
