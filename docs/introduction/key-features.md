# Key Features

## NFT Car Collection

* **4 Brands** — Lamborghini, Ferrari, Ford, Chevrolet
* **4 Rarity Tiers** — Common, Rare, Epic, Legendary
* **Unique Stats** — Speed, Acceleration, Handling, Drift
* **Spare Parts** — Wheels, Engine, Body, Shocks with brand compatibility
* **2-4 Equipment Slots** — based on car rarity

## Gacha System

* **Commit-Reveal Pattern** — cryptographically fair, no server manipulation
* **3 Gacha Tiers** — Economy, Sport, Hypercar with escalating prices and better odds
* **On-Chain Verification** — every pull is verifiable on the blockchain

## Multi-Mode Racing

| Mode | Type | Description |
|------|------|-------------|
| **Drag Race** | 2D Multiplayer | Sprint to the finish line |
| **Endless Race** | 3D Singleplayer | Dodge obstacles, collect power-ups, survive as long as possible |
| **Multiplayer Battle** | 3D Multiplayer | Real-time racing against other players via WebSocket |

## Marketplace

* **Peer-to-peer trading** — list and buy NFT cars and spare parts
* **On-chain settlement** — all trades finalized via smart contracts
* **Fee structure** — transparent marketplace and royalty fees in basis points

## Prediction Market

* **Pool-based betting** — stake OCT tokens on race outcomes
* **Proportional payouts** — winners share the pool proportional to their bet
* **On-chain settlement** — results verified and distributed automatically

## Quest System

* **Daily Quests** — log in, complete races, pull gacha
* **Weekly Quests** — win races, cover distance, accumulate achievements
* **Token Rewards** — earn OCT tokens for completing quest objectives

## Real-World Assets (RWA)

* **Physical Diecast Models** — legendary NFT cars can be redeemed for real products
* **On-Chain Claims** — claim process tracked and verified on blockchain
* **Shipping Tracking** — full fulfillment pipeline from claim to delivery
