# Tech Stack

## Frontend

| Technology | Purpose |
|-----------|---------|
| **Next.js 15** | React framework with App Router |
| **React 19** | UI component library |
| **Tailwind CSS** | Utility-first styling |
| **@onelabs/dapp-kit** | OneChain wallet integration |
| **@onelabs/sui** | Sui SDK for OneChain |
| **@tanstack/react-query** | Data fetching and caching |
| **Sonner** | Toast notifications |
| **Lucide React** | Icon library |
| **next-pwa** | Progressive Web App support |

## Game Clients

| Technology | Purpose |
|-----------|---------|
| **Phaser 3** | 2D game engine (Drag Race) |
| **Three.js** | 3D game engine (Endless Race, Multiplayer) |
| **Socket.io Client** | Real-time WebSocket communication |

## Backend

| Technology | Purpose |
|-----------|---------|
| **Express.js** | HTTP API framework |
| **TypeScript** | Type-safe server code |
| **Prisma ORM** | Database access and migrations |
| **Socket.io** | WebSocket server for real-time games |
| **ioredis** | Redis client with TLS support |
| **jsonwebtoken** | JWT authentication |
| **@noble/ed25519** | Ed25519 cryptographic signing |
| **Joi** | Request validation |
| **Helmet** | HTTP security headers |
| **express-rate-limit** | API rate limiting |
| **Winston** | Structured logging |

## Database

| Technology | Purpose |
|-----------|---------|
| **PostgreSQL** (Neon) | Primary data store |
| **Redis** (Upstash) | Cache, game state, sessions |

## Blockchain

| Technology | Purpose |
|-----------|---------|
| **OneChain** | Sui-based L1 blockchain |
| **Move** | Smart contract language |
| **@mysten/sui.js** | Sui SDK for backend |

## Infrastructure

| Service | Purpose |
|---------|---------|
| **Vercel** | Frontend hosting + serverless functions |
| **Railway** | Backend hosting (Docker) |
| **Neon** | Managed PostgreSQL |
| **Upstash** | Managed Redis with TLS |
